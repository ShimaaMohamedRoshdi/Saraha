# Saraha

## Setup

Install dependencies with `npm install`, then configure the environment variables
below before starting the application with `node index.js`.

| Variable | Description |
| --- | --- |
| `EMAIL_USER` | Gmail address used to send OTP emails |
| `EMAIL_PASS` | Gmail app password for that account |
| `JWT_SECRET` | Secret used to sign authentication tokens |

Set these variables in your hosting environment or local shell. Do not commit
credentials or `.env` files.
